# Sofia Drive

A driving simulator set in Sofia, Bulgaria. It has a real manual gearbox with a clutch you can stall, plus
a 2000 hp automatic hypercar. Streets come from OpenStreetMap and Sofia's open data. The game also has AI
traffic that follows the rules of the road, trams, buses, pedestrians and police.

## Download

Get **SofiaDrive.exe** from the [latest release](https://github.com/BorisBS23/sofia-drive/releases/latest)
and double-click it. Nothing to install.
- **Window:** it opens the game in its own Chrome or Edge window. Keep the small console window open while
  you play; close it to quit.
- **SmartScreen:** Windows may warn on first launch because the exe isn't code-signed. Click *More info →
  Run anyway*.
- **Updates itself:** at launch it checks for a newer release, downloads it in the background and verifies
  it. The new version starts the next time you open the game. Run it with `--no-update` to turn this off.

Windows 10/11, 64-bit. The game runs offline; updates, live transit and the optional 3D city need
internet.
